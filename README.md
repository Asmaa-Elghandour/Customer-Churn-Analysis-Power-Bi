# 📊 Telecom Customer Churn Analysis Report (Power BI)

## 🌟 Project Overview
This Power BI project provides an in-depth, proactive analysis of **Customer Churn** for a telecommunications or service provider.  
The primary goal is to identify **high-risk customer segments** and uncover the **root causes driving customers away**.  
The report facilitates **data-driven decision-making** for management, aiming to **lower churn rates** and increase **Customer Lifetime Value (CLV)**.

---

## 💡 Key Insights and Findings
Based on the analysis across the four report pages, the following critical insights were identified:

- **Overall Churn Rate:** 26.86%, indicating an urgent need for retention strategies.  
- **Primary Churn Drivers:** Competitor Offers and poor Support Attitude account for over **60%** of churn cases.  
- **Highest Risk Segment:** Customers with **Month-to-Month Contracts** and **Senior Citizens** show the highest propensity to churn.  
- **Service Paradox:** Customers with an **International Plan** still have high churn, suggesting dissatisfaction with quality or cost.

---

## 🛠️ Tools and Technologies Used
- **Power BI Desktop:** For data visualization, report design, and modeling.  
- **Power Query (M Language):** For data cleaning, transformation, and preparation.  
- **DAX (Data Analysis Expressions):** For analytical measures and KPIs (e.g., Churn Rate).  

---

## 📁 Report Structure and Analysis Areas
The report is segmented into **four interactive pages**, each focusing on a key aspect of churn analysis:

1. **Overview** – Main KPIs and visual breakdown of churn reasons.  
2. **Demographics** – Churn by age, gender, and income, emphasizing senior segment risk.  
3. **Contract & Payment** – Analysis of contract type and payment methods (highlighting month-to-month instability).  
4. **International Plan** – Comparison of churn behavior among plan subscribers and non-subscribers.
